# pk42ac

**AI Security & AgentOps Builder based in Seoul.**

I build security tools for AI coding agents, document-security classifiers, and full-stack AI products from model training to deployment.

## Focus

- AI agent security, MCP/Codex/Claude Code risk scanning
- LLM and multimodal ML applications for security and fairness
- Document security classification and DLP-style systems
- Full-stack AI products with practical demos, APIs, and evaluation loops

## Featured Projects

### [AgentGuard](https://github.com/Sungho-pk42ac/agentguard)
Security scanner for AI coding agents, MCP configs, transcripts, and PR diffs.

- TypeScript CLI/package
- SARIF output for GitHub code scanning
- GitHub Actions PR comment workflow
- 167 automated tests passing

### [Document-classification-CSO](https://github.com/Sungho-pk42ac/Document-classification-CSO)
Qwen3-14B LoRA classifier for Korean document security labels: C / S / O.

- Qwen3-14B + LoRA fine-tuning
- FastAPI REST API + Web UI
- Evaluation pipeline with Accuracy / Macro F1 / JSON validity metrics
- HuggingFace model release

### [KISIA Project](https://github.com/Sungho-pk42ac/kisia-project)
AI DLP system for detecting and blocking sensitive data leakage.

- 2025 AI security project award work
- PII detection and policy-driven block/mask flow
- FastAPI backend, dashboard, proxy, and monitoring components

### [DACON SKKU Multimodal AI Bias Challenge](https://github.com/Sungho-pk42ac/dacon-2026-skku-multimodal-ai-bias-challenge)
Multimodal VQA bias mitigation solution with abstention-aware policy.

- Qwen3-VL-8B based competition solution
- GRPO / hard-negative training pipeline
- Reproducible training, inference, and submission structure

### [SceneForge](https://github.com/Sungho-pk42ac/SceneForge)
Local-first 3D interactive scene editor and hash-based public viewer.

- TypeScript-first 3D editor architecture
- Local-first scene state
- Public viewer concept for shareable scenes
